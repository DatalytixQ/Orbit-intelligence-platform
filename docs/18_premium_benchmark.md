# PREMIUM BENCHMARK

## 1. Objective
Extract Premium Enterprise UI principles from industry leaders (Stripe, Linear, Vercel, Power BI, Looker) to define the specific standards ERP Intelligence Foundation must meet.

## 2. Extracted Principles

### A. Stripe Dashboard (Information Hierarchy & Density)
- **Principle**: High contrast for primary numbers, extremely subtle borders for cards. Backgrounds are almost exclusively pure white or soft slate.
- **Application**: Remove harsh pink/red alert backgrounds. Use subtle tinted backgrounds with high-contrast text metrics.

### B. Linear (Typography & Whitespace)
- **Principle**: Intense discipline in font scaling. Tracking is tight on large numbers. Sentences are muted. Zero ALL CAPS outside of microscopic kickers.
- **Application**: Eradicate ALL CAPS headers. Scale down secondary text. Use `Inter` for tables and `Geist` for massive KPIs.

### C. Vercel (Interaction & Navigation)
- **Principle**: Floating, context-aware command palettes and assistants. The main canvas is sacred and never compressed by persistent right-sidebars.
- **Application**: Transform the DQBot from a fixed 300px layout killer into a bottom-right floating widget.

### D. Microsoft Fabric / Power BI (Decision Support)
- **Principle**: Dashboards should state conclusions, not just plot lines.
- **Application**: Every chart must have an "Executive Read" (Level 3 Hierarchy) summarizing the chart's meaning in a single sentence.
